# Course Map

## Part I — How Commercial IT Works
- 1. [IT Organization Structure](/training/part-1-commercial-it/it-organization-structure) — Understand how business, product, architecture, engineering, security, data, operations and support teams fit together.
- 2. [Business Domains: Retail, Banking, Healthcare & Supply Chain](/training/part-1-commercial-it/business-domains) — Recognize common business processes and learn how engineers acquire domain knowledge.
- 3. [Roles and Responsibilities in an IT Shop](/training/part-1-commercial-it/roles-responsibilities) — Differentiate Product Owner, Scrum Master, Architect, Developer, QA, DevOps, SRE, Security and related roles.
- 4. [Agile, Scrum, Sprints and Retrospectives](/training/part-1-commercial-it/agile-scrum) — Understand the ceremonies, artifacts and collaboration model used by many commercial teams.
- 5. [Jira and Confluence in Daily Work](/training/part-1-commercial-it/jira-confluence) — Follow requirements from backlog through documentation, implementation, review and completion.
- 6. [Software Development Life Cycle](/training/part-1-commercial-it/sdlc) — Trace a change from business request through analysis, build, test, release and production support.
- 7. [Git, Branching, Pull Requests and Team Development](/training/part-1-commercial-it/git-team-development) — Use source control safely and understand the workflow around collaborative code changes.
## Part II — How Modern Applications Work
- 8. [Internet, DNS, HTTP and TLS](/training/part-2-modern-apps/internet-dns-http-tls) — Follow a browser request from domain lookup through encrypted HTTP communication.
- 9. [High-Level Web Application Architecture](/training/part-2-modern-apps/web-app-architecture) — Understand browser, edge, UI, API, service, data and integration layers.
- 10. [REST APIs, HTTP Methods, Status Codes and JSON](/training/part-2-modern-apps/rest-api-json) — Read and reason about practical request/response contracts used by enterprise APIs.
- 11. [Relational Databases and SQL](/training/part-2-modern-apps/database-sql) — Understand tables, keys, joins, transactions, indexes and core SQL operations.
- 12. [ORM, JPA and Hibernate](/training/part-2-modern-apps/orm-jpa-hibernate) — Understand how Java objects map to relational data and where ORM abstractions help or hurt.
- 13. [Batch Jobs and Scheduled Processing](/training/part-2-modern-apps/batch-processing) — Contrast synchronous web requests with scheduled, bulk and reconciliation workloads.
- 14. [Messaging and Event-Driven Architecture](/training/part-2-modern-apps/messaging-event-driven) — Understand producers, consumers, queues, topics, retries and asynchronous decoupling.
## Part III — Enterprise Application Development
- 15. [Java Refresher for Commercial Development](/training/part-3-enterprise-development/java-refresh) — Review the Java concepts most directly used in Spring-based enterprise applications.
- 16. [Spring Core and Dependency Injection](/training/part-3-enterprise-development/spring-core-di) — Understand beans, inversion of control, dependency injection and application composition.
- 17. [Spring Boot 4 and Spring MVC](/training/part-3-enterprise-development/spring-boot-webmvc) — Build controllers, services and web endpoints using modern Spring Boot conventions.
- 18. [Spring Data JPA](/training/part-3-enterprise-development/spring-data-jpa) — Use repositories, query methods and transactions to implement a clean persistence layer.
- 19. [Spring Security Fundamentals](/training/part-3-enterprise-development/spring-security) — Understand filter chains, authentication, authorization and secured application boundaries.
## Part IV — Enterprise Security & IAM
- 20. [Application Security Fundamentals](/training/part-4-enterprise-security/security-fundamentals) — Learn least privilege, TLS, secrets, OWASP risks and the shared responsibility model.
- 21. [Identity and Access Management](/training/part-4-enterprise-security/iam) — Separate identity, authentication, authorization, roles, groups, federation and lifecycle management.
- 22. [OAuth 2.0](/training/part-4-enterprise-security/oauth2) — Understand clients, authorization servers, resource servers, scopes and authorization grants.
- 23. [OpenID Connect](/training/part-4-enterprise-security/oidc) — Understand identity tokens, user identity claims and authentication built on OAuth 2.0.
- 24. [SAML 2.0](/training/part-4-enterprise-security/saml2) — Understand enterprise browser SSO, IdP/SP roles, metadata, assertions, signing and encryption.
- 25. [Keycloak Administration and Integration](/training/part-4-enterprise-security/keycloak) — Use a real identity provider to model realms, clients, users, roles and federation.
- 26. [PKCE, JWT and Token Validation](/training/part-4-enterprise-security/pkce-jwt) — Understand proof key protection, signed token claims, issuers, audiences and JWKS validation.
## Part V — Modern Infrastructure
- 27. [Linux and Command-Line Skills](/training/part-5-infrastructure/linux-cli) — Become comfortable with the commands and diagnostics common in servers, containers and CI jobs.
- 28. [Docker and Containers](/training/part-5-infrastructure/docker) — Package an application and understand images, containers, ports, volumes and environment variables.
- 29. [Kubernetes Fundamentals](/training/part-5-infrastructure/kubernetes) — Recognize pods, deployments, services, ingress, configuration and secrets without becoming a cluster administrator.
- 30. [Cloud Computing Fundamentals](/training/part-5-infrastructure/cloud-computing) — Understand compute, storage, managed databases, identity and shared responsibility across major clouds.
- 31. [Cloud Networking Fundamentals](/training/part-5-infrastructure/cloud-networking) — Understand VNets/VPCs, subnets, routing, firewalls, load balancers, private endpoints and DNS.
## Part VI — Software Delivery & Operations
- 32. [CI/CD Pipelines](/training/part-6-delivery-operations/cicd) — Follow code from commit through build, test, scanning, artifact creation and deployment.
- 33. [DEV, TEST, QA, UAT, STAGE and PROD](/training/part-6-delivery-operations/environments) — Understand why commercial systems use multiple environments and different controls in each.
- 34. [Testing Strategy](/training/part-6-delivery-operations/testing) — Differentiate unit, integration, API, UI, performance and regression testing.
- 35. [Application Logging](/training/part-6-delivery-operations/logging) — Write and use logs as evidence for diagnosis rather than as unstructured console noise.
- 36. [Monitoring and Observability](/training/part-6-delivery-operations/monitoring-observability) — Understand metrics, logs, traces, alerts and service health.
- 37. [Systematic Troubleshooting](/training/part-6-delivery-operations/troubleshooting) — Use evidence, reproduction, logs, network tools and component isolation to find root causes.
- 38. [Production Incidents and Root Cause Analysis](/training/part-6-delivery-operations/incident-rca) — Understand incident response, impact, containment, restoration, RCA and corrective action.
## Part VII — Data Engineering & Analytics
- 39. [ETL and ELT](/training/part-7-data/etl) — Understand extraction, transformation, loading and common enterprise integration patterns.
- 40. [Data Warehouses](/training/part-7-data/data-warehouse) — Understand dimensional analytics, curated reporting data and warehouse workloads.
- 41. [Data Lakes and Lakehouse Concepts](/training/part-7-data/data-lake) — Understand object storage, raw/curated zones, medallion architecture and analytical data management.
- 42. [Streaming and Near-Real-Time Data](/training/part-7-data/streaming) — Understand events, streams, ingestion and how operational data becomes available for fast analytics.
- 43. [Analytics and Machine Learning](/training/part-7-data/analytics-ml) — Understand how governed business data becomes features, models, predictions and decision support.
## Part VIII — AI-Era Engineering
- 44. [Generative AI Fundamentals](/training/part-8-ai-engineering/generative-ai) — Understand models, tokens, context, prompting, hallucination and responsible use.
- 45. [LLM Application Architecture](/training/part-8-ai-engineering/llm-architecture) — Understand how applications safely call models through gateways, policies, grounding and observability.
- 46. [Retrieval-Augmented Generation](/training/part-8-ai-engineering/rag) — Ground model responses using enterprise documents and controlled retrieval.
- 47. [LLM Tool and Function Calling](/training/part-8-ai-engineering/tool-calling) — Connect models to deterministic APIs, databases and enterprise operations.
- 48. [Agentic AI](/training/part-8-ai-engineering/agentic-ai) — Understand planning, tool selection, state, validation, retries and human-in-the-loop controls.
- 49. [AI Coding Agents](/training/part-8-ai-engineering/coding-agents) — Use modern coding assistants while preserving engineering ownership, review and testing.
- 50. [Vibe Coding: Benefits, Limits and Guardrails](/training/part-8-ai-engineering/vibe-coding) — Move fast with AI-generated code without losing architecture, security, testability or maintainability.
- 51. [AI Security and Governance](/training/part-8-ai-engineering/ai-security-governance) — Understand data leakage, prompt injection, authorization, auditability and organizational AI controls.
## Part IX — Professional Engineering
- 52. [Architecture Thinking](/training/part-9-professional-engineering/architecture-thinking) — Reason about requirements, constraints, tradeoffs, dependencies and non-functional requirements.
- 53. [Code Review and Engineering Quality](/training/part-9-professional-engineering/code-review) — Give and receive useful reviews and recognize maintainability, security and correctness risks.
- 54. [Technical Documentation](/training/part-9-professional-engineering/documentation) — Create documentation that another engineer can operate, troubleshoot and extend.
- 55. [Working with Product and Business Teams](/training/part-9-professional-engineering/working-with-product) — Translate between business outcomes, requirements, acceptance criteria and technical implementation.
- 56. [Technical Communication](/training/part-9-professional-engineering/communication) — Communicate clearly with engineers, managers, architects, executives and non-technical stakeholders.
- 57. [Cybersecurity Mindset for Every Engineer](/training/part-9-professional-engineering/cybersecurity-mindset) — Treat identity, secrets, data, dependencies and operational access as everyday engineering responsibilities.
## Part X — Commercial Capstone
- 58. [Capstone: Requirements and Jira Backlog](/training/part-10-capstone/capstone-requirements) — Convert a business problem into actors, requirements, user stories and acceptance criteria.
- 59. [Capstone: Architecture and Security Design](/training/part-10-capstone/capstone-architecture) — Design the web, API, database, IAM, deployment and operational architecture before coding.
- 60. [Capstone: Build, Deploy, Operate and Improve](/training/part-10-capstone/capstone-build-operate) — Implement the system, deploy it, observe it, simulate an incident and complete an RCA.
