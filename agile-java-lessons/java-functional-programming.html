1. Functional interfaces and lambdas

import java.util.function.*;
Predicate<String> nonblank = s -> s != null && !s.isBlank();
Function<String, Integer> length = String::length;
Consumer<String> print = System.out::println;
Supplier<String> supplier = () -> "ready";

Java functional interfaces have one abstract method. Common choices include Predicate, Function, Consumer, and Supplier.

2. Streams: filter, map and collect

import java.util.*;
import java.util.stream.*;

List<String> names = List.of("Ada", "Bob", "Alice");
List<String> result = names.stream()
    .filter(n -> n.startsWith("A"))
    .map(String::toUpperCase)
    .toList();
System.out.println(result); // [ADA, ALICE]

Intermediate operations are lazy. Terminal operations trigger evaluation. Avoid stateful side effects in stream pipelines.

3. Optional and grouping

Optional<String> sku = Optional.of("P100");
String label = sku.filter(s -> s.startsWith("P"))
    .orElse("UNKNOWN");

Map<Integer, List<String>> byLength = List.of("a", "bb", "cc")
    .stream().collect(Collectors.groupingBy(String::length));

Optional is useful for return values that may be absent. Avoid using it indiscriminately for DTO fields or persistence entities.
