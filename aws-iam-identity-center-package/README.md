# AWS IAM & IAM Identity Center

Place the main lesson and wrapper HTML files in `src/main/resources/templates/internships/`, the controller in `src/main/java/com/commercialit/bootcamp/controller/`, and the PNG in `src/main/resources/static/images/`.

The controller maps only `/internships/cloud-computing/aws/iam-identity-center`. Do not edit shared `topic.html`, existing controllers, or the navigation bar. Check for pre-existing mapping with `grep -R` before copying the controller.

Build and restart the Spring Boot application. Runtime integration has not been tested here.
