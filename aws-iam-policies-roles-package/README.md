# AWS IAM Policies, Roles & STS

This package provides a complete Thymeleaf lesson, PNG architecture diagram (7680x4320 output, upscaled from 1672x941 generated source), a dedicated controller for `/internships/cloud-computing/aws/iam-policies-roles`, and an installation script.

The lesson template itself includes `base :: layout`; it does not need an additional wrapper. Existing navigation, shared templates and other lessons are unchanged.

From the project root run `unzip -o ~/Downloads/aws-iam-policies-roles-package.zip` then `bash aws-iam-policies-roles-package/install.sh`, then `mvn clean install` and restart the app.

The 8K PNG is an upscale of the generated source, not native 8K detail.
