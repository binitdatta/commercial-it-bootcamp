# Commercial IT Bootcamp — React, Python and Cloud lessons

Run from the project root after unzipping:

```bash
python3 react-python-cloud-lessons/install_react_python_cloud.py
```

Requires the existing `InternshipController.java` and template folder. The installer makes a controller backup, checks for preexisting conflicts, and adds dedicated mappings for only six URLs:

- `/internships/react-crash-course`
- `/internships/python-3-crash-course`
- `/internships/cloud-computing`
- `/internships/cloud-computing/aws`
- `/internships/cloud-computing/google-cloud`
- `/internships/cloud-computing/azure`

It does not touch the generic topic/section templates, navbar, existing lessons or Spring Security. Commands that create cloud resources can incur costs: the labs use read-only validation commands where feasible.
