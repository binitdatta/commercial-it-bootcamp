Course philosophy

Teach the connective tissue of commercial IT.

The platform is intentionally built as a real application so course lessons can point to working code, database objects, security flows and operational artifacts.

Each training URL corresponds to an individual Thymeleaf file. That makes it easy to replace one placeholder at a time with a full video lesson while preserving the same navbar, security model and visual language.

Reference stack

  • Java 21
  • Spring Boot 4.1.1
  • Spring Security / OAuth2 / OIDC
  • Keycloak
  • Thymeleaf + Bootstrap 5.3.8
  • Spring Data JPA / Hibernate
  • MySQL 8.x
