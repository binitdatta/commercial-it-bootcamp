Secured REST API

The same application is an OAuth2 Resource Server for /api/**.

1. Obtain a machine-to-machine token

curl -s -X POST \ http://localhost:8080/realms/commercial-it-bootcamp/protocol/openid-connect/token \ -H 'Content-Type: application/x-www-form-urlencoded' \ -d 'grant_type=client_credentials' \ -d 'client_id=commercial-it-bootcamp-api' \ -d 'client_secret=demo-api-secret-change-me'

The client secret is intentionally a local training secret. Never commit real secrets to a repository.

2. Call a protected endpoint

curl http://localhost:8081/api/products \ -H "Authorization: Bearer $ACCESS_TOKEN"

3. Create an order

curl -X POST http://localhost:8081/api/orders \ -H "Authorization: Bearer $ACCESS_TOKEN" \ -H 'Content-Type: application/json' \ -d '{"customerId":1,"lines":[{"productId":5,"quantity":1}]}'
