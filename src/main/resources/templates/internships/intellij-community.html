1. Choose the free IntelliJ IDEA functionality

Important naming change (2025.3 onward): JetBrains combined the former Community Edition and Ultimate installers into a single IntelliJ IDEA distribution. The free core features remain available for commercial and non-commercial Java development. You do not need to buy Ultimate for this bootcamp.
OptionWhat interns should know
Unified IntelliJ IDEA (current)Download one installer, then use the free core features for Java/Kotlin, Maven, tests, Git, basic database tools and Spring project creation.
Ultimate subscriptionUnlocks advanced professional features; optional, not required for the labs in this lesson.
Legacy Community Edition (≤2025.2)Older separate installers exist, but for new setups use the current unified IntelliJ IDEA.

2. Understand the development toolchain

ComponentPurpose
IntelliJ IDEA IDEEditor, refactoring, run/debug UI, test runner and Git UI.
JetBrains RuntimeRuns the IDE itself; not necessarily the JDK used to compile your project.
JDK 21Project SDK, Java compiler and runtime. Configure explicitly for Java 21 projects.
MavenBuild system that resolves dependencies, compiles, tests and packages Java applications.
GitSource version control; IDE integrates with the Git executable installed on your machine.

Prerequisites: JDK 21 installed, internet access for initial Maven dependency resolution, and Git installed for the optional source-control exercise.

3. Install on macOS (Apple Silicon and Intel)

  1. Open the official download page.
  2. Choose the macOS installer that matches your hardware: Apple Silicon (ARM64) or Intel (x64). To verify architecture, use the command below.
  3. Open the downloaded DMG, drag IntelliJ IDEA into Applications, then launch it.
  4. Complete first-run prompts; choose free functionality. An Ultimate trial is optional.
  5. For optional centralized install/update management, use JetBrains Toolbox App.
uname -m
# arm64 = Apple Silicon; x86_64 = Intel
java -version
/usr/libexec/java_home -V
Using the wrong architecture build can reduce performance or prevent startup. Prefer the native build for your Mac.

4. Install on Windows 10/11

  1. Download the Windows installer from JetBrains. Choose the matching architecture.
  2. Run the installer and choose an installation directory.
  3. If offered, enable the Open Folder as Project Explorer integration and PATH launcher shortcut as appropriate.
  4. Launch IntelliJ IDEA and complete first-run settings.
  5. Confirm Java 21 is installed separately by opening PowerShell and running:
java -version
javac -version
where.exe java
The IDE may ship with a runtime for itself; do not assume that runtime is the SDK for your projects.

5. Install on Linux (Ubuntu, Debian, Fedora)

Preferred paths: JetBrains Toolbox or the official Linux tarball. Choose the package corresponding to your CPU architecture and supported desktop environment.

  1. Download the Linux distribution from the official website.
  2. Extract the archive to a directory your account can access (for example, under ~/apps).
  3. Run the bundled launch script from its bin folder; actual extracted directory names vary by release.
  4. From the IDE, optionally create a desktop entry using its Tools menu if available.
uname -m
java -version
mkdir -p "$HOME/apps"
# Extract your downloaded archive in $HOME/apps.
# Then run the idea.sh script within its extracted bin/ directory.
Avoid copying a hard-coded extraction folder name or downloading third-party binaries. Distribution-specific Snap/Flatpak methods may exist; always verify publisher and update policy.

6. Configure Project SDK, Maven and the IDE

Java 21 SDK

  1. Open File → Project Structure → Project (macOS shortcut and menu placement may vary by IDE version).
  2. Set SDK to a locally installed JDK 21. If absent, choose Add SDK and select the JDK installation directory.
  3. For Maven projects, check the Maven importer and runner JDK in Settings → Build, Execution, Deployment → Build Tools → Maven.
  4. For a new project, configure Java language level and Maven compiler release to 21.

Recommended basics

Enable auto-import prompts for Maven changes, use built-in inspections, choose consistent formatting and avoid committing IDE-specific user settings. Inspect the Plugins screen and install only extensions from trusted publishers.

java -version
mvn -version
# Both should report the intended JDK version for the shell build.
IntelliJ's Project SDK, Maven runner JDK and terminal JAVA_HOME can be different. A project building in the IDE does not guarantee it builds from the command line.

7. Hands-on: create a Java 21 Maven project

  1. Choose New Project → Java, select Maven as the build system, set JDK 21 and name the project intern-java21.
  2. Create package com.bootcamp.lab in src/main/java.
  3. Create Welcome.java with the class below.
  4. Run the green gutter triangle beside main.
  5. Run Maven compile and test goals. Confirm the terminal and IDE both succeed.
package com.bootcamp.lab;

public class Welcome {
    public static void main(String[] args) {
        String intern = "Java Intern";
        System.out.println("Hello, " + intern + " — Java "
            + Runtime.version().feature());
    }
}

Expected output includes Hello, Java Intern — Java 21 when launched with JDK 21. Use Run → Edit Configurations to confirm selected JRE if output differs.

8. Debugging, unit tests and Git workflow

  1. Click the gutter beside System.out.println to add a breakpoint. Choose Debug instead of Run.
  2. Inspect variables in the debugger; use Step Over and Resume Program.
  3. Create src/test/java and a JUnit 5 test using your Maven project's test dependencies.
  4. Use the Git menu to initialize a repository, add .gitignore, commit source code and inspect diffs.
# Example project .gitignore entries
target/
.idea/workspace.xml
*.iml
Avoid committing credentials, personal configuration, local run logs or database passwords. Review the staged diff before committing.

10. Troubleshooting reference

SymptomLikely cause / correction
JDK 21 missing from SDK listInstall a JDK 21 distribution and point Project Structure to its home directory.
Unsupported class file versionRun/debug JRE is older than the compiled target; align JDK and Maven settings.
Maven dependencies unresolvedCheck connectivity, corporate proxy, Maven settings and configured repository credentials.
Build works in IDE but fails in terminalCompare java -version, mvn -version, Project SDK and Maven runner JDK.
Source directory is not recognizedReimport Maven project; confirm pom.xml and standard project structure.
Git actions unavailableInstall Git separately and configure its executable in IDE version-control settings.
