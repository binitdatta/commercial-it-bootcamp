1. How to use this Java crash course

This pathway assumes JDK 21 is installed. Work through the seven topics in order, writing and running code after each module. Use an IDE if preferred, but understand the terminal commands.

java -version
javac -version
mkdir java-labs && cd java-labs

Java 21 is an LTS release. The course concentrates on core Java skills used in Spring Boot services, DTOs, validation, persistence and integration code.

2. Seven core Java modules

1. Data Types →

Primitives, objects, String, records, conversions and null safety.

2. Generics →

Type parameters, collections, bounds and safe APIs.

3. Logical Decision Making →

Conditions, switch expressions, pattern matching and validation.

4. Loops →

for, while, enhanced for and stream tradeoffs.

5. Math →

Integer arithmetic, BigDecimal, precision and rounding.

6. Dates →

java.time, time zones, intervals and ISO-8601.

7. Functional Programming →

Lambdas, method references, streams, Optional and functions.

3. Mini capstone: order pricing engine

Build a command-line pricing prototype in JDK 21. Each lesson contributes one piece:

  • Data types model an order and line items.
  • Generics define typed lists and repositories.
  • Decision making validates discounts and order status.
  • Loops calculate totals.
  • Math uses BigDecimal for money.
  • Dates establish an order timestamp and expected delivery window.
  • Streams summarize totals by category.
Keep monetary computations in BigDecimal, not floating-point primitives. Reject invalid discounts and demonstrate tests for boundary cases.

4. How you will be assessed

Each topic contains working code, a practice assignment, and knowledge checks. Commit one Java source file and one short README per topic. For the mini capstone submit a Git repository with JDK 21 instructions, deterministic test cases, and sample output.
