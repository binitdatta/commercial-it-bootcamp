1. for, while, do-while and enhanced for

for (int i = 0; i < 3; i++) System.out.println(i);

int retries = 0;
while (retries < 3) {
    retries++;
}

for (String sku : List.of("A", "B")) {
    System.out.println(sku);
}

A do-while loop executes at least once. Ensure every unbounded loop has a termination or cancellation strategy.

2. Break, continue and safe modification

for (int n = 1; n <= 10; n++) {
    if (n % 2 == 0) continue;
    if (n > 7) break;
    System.out.println(n);
}

Do not structurally mutate an ArrayList during a for-each iteration; use an iterator removal or removeIf where appropriate.

3. Complexity and collection choice

A pass over n elements is typically O(n); nested full scans are often O(n²). For key lookup, HashMap commonly gives average-case O(1) operations, though worst-case and memory characteristics still matter.

int total = 0;
for (int quantity : new int[]{2, 3, 5}) {
    total += quantity;
}
System.out.println(total); // 10
