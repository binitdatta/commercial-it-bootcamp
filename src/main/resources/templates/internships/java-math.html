1. Numeric arithmetic and overflow

int result = 7 / 2;           // 3
double average = 7.0 / 2;    // 3.5
int checked = Math.addExact(2_000_000_000, 100);
// Throws ArithmeticException on overflow when sum exceeds int range

Java integral division truncates toward zero. Use Math.addExact, multiplyExact when integer overflow must be detected.

2. BigDecimal for money

import java.math.BigDecimal;
import java.math.RoundingMode;

BigDecimal unit = new BigDecimal("19.95");
BigDecimal qty = BigDecimal.valueOf(3);
BigDecimal subtotal = unit.multiply(qty);
BigDecimal tax = subtotal.multiply(new BigDecimal("0.0825"));
BigDecimal total = subtotal.add(tax).setScale(2, RoundingMode.HALF_UP);
System.out.println(total);

Use agreed business rounding rules and currency handling. BigDecimal.equals considers scale; compareTo tests numeric equality.

3. Math utilities and rounding

double root = Math.sqrt(81);
int max = Math.max(3, 7);
long exact = Math.multiplyExact(200L, 3L);
// BigDecimal.divide may require scale/rounding mode

Math.random() is not suitable for cryptographic secrets. Use SecureRandom for security-sensitive randomness.
