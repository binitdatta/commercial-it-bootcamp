1. Java installation fundamentals

ComponentPurpose
JDK (Java Development Kit)Everything needed to develop Java: compiler (javac), runtime (java), JShell, tools and standard libraries.
JVM (Java Virtual Machine)Executes compiled Java bytecode. The JVM implementation is part of the installed Java runtime.
JRE (Java Runtime Environment)Runtime components without the complete developer toolchain. For this bootcamp, install the JDK, not a runtime-only package.
JAVA_HOMEEnvironment variable identifying the JDK installation directory—not the bin directory.
PATHSearch path the shell uses to find commands such as java, javac and mvn.

Why 21? Java 21 is a long-term-support (LTS) release and a consistent baseline for this training course. The precise patch number (21.0.x) will change as security updates are released.

2. Choose an OpenJDK distribution

Recommended for consistent labs: Eclipse Temurin 21, a build of OpenJDK distributed by the Eclipse Adoptium project. Other OpenJDK distributions can also work, including operating-system OpenJDK packages and Microsoft Build of OpenJDK.

Always select version 21, the JDK package, and the correct architecture: aarch64/ARM64 for Apple Silicon or ARM systems, and x64/AMD64 for most Intel/AMD machines.

3. macOS installation

Apple Silicon (M1/M2/M3/M4/…) and Intel

Option A · Install with Homebrew (recommended)

1
Open Terminal. If Homebrew is not installed, follow its official installation instructions at brew.sh.
2
Install the version-pinned Temurin 21 cask, then locate its registered JDK home:
brew update
brew install --cask temurin@21
/usr/libexec/java_home -V
/usr/libexec/java_home -v 21
3
For the default zsh shell, make Java 21 the active JDK in new terminal sessions:
cat >> ~/.zshrc <<'END_JAVA_HOME_SETUP'
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH="$JAVA_HOME/bin:$PATH"
END_JAVA_HOME_SETUP
source ~/.zshrc
java -version
javac -version
echo "$JAVA_HOME"
These lines are for zsh. For Bash, put the two export statements in your active Bash startup file. Check your shell with echo "$SHELL". Use a different heredoc marker if copying into another script.

Option B · Graphical PKG installer

Download the macOS JDK 21 PKG from Adoptium. Choose ARM64/AArch64 for Apple Silicon or x64 for Intel. Run the installer; then use /usr/libexec/java_home -V to confirm macOS registered your JDK.

Version caution: brew install --cask temurin installs the current major release, which might not be 21. Use temurin@21.

4. Windows installation

Windows 10 / 11 · PowerShell

Option A · Install with winget

Launch PowerShell and confirm winget is present. Install the exact Temurin 21 package:

winget --version
winget install --id EclipseAdoptium.Temurin.21.JDK --exact --accept-package-agreements --accept-source-agreements

Close and reopen PowerShell, then validate:

java -version
javac -version
where.exe java
$env:JAVA_HOME

Option B · Windows MSI

Download the Windows JDK 21 MSI installer from Temurin 21 releases. Select your CPU architecture and enable the installer's JAVA_HOME and PATH options if offered. Reopen your terminal after installation.

Setting JAVA_HOME manually

  1. Open Start → Edit the system environment variables → Environment Variables.
  2. Set JAVA_HOME to the actual installed JDK 21 root, such as C:\Program Files\Eclipse Adoptium\jdk-21...-hotspot (example only; use the directory you see).
  3. Add %JAVA_HOME%\bin to your user or system Path and move it ahead of incorrect Java versions if necessary.
  4. Open a new terminal and confirm java -version and javac -version both show 21.
Shell syntax: PowerShell displays $env:JAVA_HOME; Command Prompt uses echo %JAVA_HOME%.

5. Linux installation

Ubuntu 24.04 LTS / compatible Debian systems

APT package

sudo apt update
sudo apt install -y openjdk-21-jdk
java -version
javac -version
readlink -f "$(command -v javac)"

If you have several Java versions installed:

sudo update-alternatives --config java
sudo update-alternatives --config javac

The package name and availability depend on the Linux release and enabled repositories.

Fedora / compatible RPM distributions

DNF package

sudo dnf install -y java-21-openjdk-devel
java -version
javac -version
sudo alternatives --config java
sudo alternatives --config javac

Enterprise Linux distributions may require a supported repository or different package naming. For vendor consistency, follow Adoptium's Linux repository guide and install temurin-21-jdk.

JAVA_HOME on Linux

Inspect the compiler's resolved path and remove the trailing /bin/javac to identify the JDK home. Paths vary by distribution and architecture.

readlink -f "$(command -v javac)"
# Example on Ubuntu: /usr/lib/jvm/java-21-openjdk-amd64/bin/javac
# Only if that matches YOUR machine:
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
export PATH="$JAVA_HOME/bin:$PATH"
echo "$JAVA_HOME"
"$JAVA_HOME/bin/javac" -version

Persist the correct export lines in ~/.bashrc (Bash) or ~/.zshrc (zsh). Launch a new shell afterwards.

Do not blindly paste the example JAVA_HOME path, particularly on ARM64 hosts.

6. Verify Java and compile your first application

Verify the Java runtime, compiler and REPL

java -version
javac -version
jshell --version

Pass: Java reports 21.0.x, and javac reports version 21. The exact vendor and patch version depend on the build.

Hands-on exercise: HelloBootcamp.java

Create a folder called java21-lab. Inside it create the following source file named HelloBootcamp.java:

public class HelloBootcamp {
    public static void main(String[] args) {
        System.out.println("Commercial IT Bootcamp - OpenJDK 21 ready!");
        System.out.println("Runtime: " + System.getProperty("java.version"));
        System.out.println("Vendor: " + System.getProperty("java.vendor"));
    }
}

Change to that folder and compile/run it:

javac HelloBootcamp.java
java HelloBootcamp

Expected: a greeting followed by a Java 21 runtime version and a vendor string. Compilation generates HelloBootcamp.class.

Explore JShell

jshell
21 * 2
System.getProperty("java.version")
/exit
Architecture: The JDK compiler translates .java source into platform-independent .class bytecode. The installed JVM executes that bytecode.

7. Configure IntelliJ IDEA, VS Code and Maven

IntelliJ IDEA

Open File → Project Structure → Project and choose JDK 21 as the Project SDK. If absent, add the JDK using its installed home directory. Ensure language level is compatible with Java 21.

Visual Studio Code

Install the Extension Pack for Java and open Java: Configure Java Runtime from the Command Palette. Set or confirm JDK 21 for your workspace.

Maven

After Maven is installed, check that it runs under Java 21:

mvn -version

For a Maven Java project, a typical compiler release property is:

<properties>
    <maven.compiler.release>21</maven.compiler.release>
</properties>

Setting a compiler release does not, by itself, change which JDK runs Maven or your IDE.
