1. Python runtime, virtual environments and packaging

Python 3 runs interpreted Python programs using CPython or an alternative implementation. Use project-specific virtual environments to isolate installed libraries.

ConceptPurpose
InterpreterExecutes Python source and bytecode
pipInstalls Python packages
venvIsolates project dependencies
pyproject.tomlDescribes project metadata and tooling configuration
Type hintsHelp static tooling; they are not runtime validation

2. Install and validate on macOS, Windows, Linux

Choose a supported Python 3 release compatible with required dependencies. Do not modify the operating system Python installation.

# macOS / Linux
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip --version

# Windows PowerShell (use the Python launcher where available)
py -3 --version
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip --version

If PowerShell execution policy blocks activation, run the environment’s python.exe directly or follow approved security policy. Verify your IDE has selected the virtual environment.

3. Variables and core types

Learn integers, floats, booleans, strings, lists, tuples, dictionaries, sets and None. Be careful with floating-point money: use Decimal.

from decimal import Decimal
order = {"id": 101, "items": ["A", "B"], "paid": False}
subtotal = Decimal("19.99") * 3
print(order["id"], subtotal)

Lab: create a dictionary representing an order with status and amount.

4. Control flow and functions

Python uses indentation to define blocks. Understand if/elif/else, for/while loops, comprehensions and function signatures.

def shipping_band(total: float) -> str:
    if total >= 100:
        return "FREE"
    elif total >= 50:
        return "STANDARD"
    return "PAID"

for amount in [20, 60, 120]:
    print(amount, shipping_band(amount))

Lab: refactor to handle invalid negative totals and add unit tests.

5. Data classes, typing and exceptions

Use dataclasses for local data structures and typing for readability. Convert and validate untrusted API input explicitly.

from dataclasses import dataclass

@dataclass(frozen=True)
class Order:
    id: int
    customer: str

def lookup_order(orders: dict[int, Order], order_id: int) -> Order:
    try:
        return orders[order_id]
    except KeyError as exc:
        raise ValueError("Order not found") from exc

Error handling should identify recoverable conditions; avoid bare except and silent failures.

6. Files, JSON and datetime

Use context managers for safe file access and timezone-aware UTC timestamps for event data.

import json
from datetime import datetime, timezone
from pathlib import Path

record = {"id": 1, "created": datetime.now(timezone.utc).isoformat()}
Path("order.json").write_text(json.dumps(record, indent=2))
print(json.loads(Path("order.json").read_text()))

Lab: load a JSON order list and write a summary CSV without leaking personal data.

7. HTTP APIs and FastAPI basics

Understand REST, status codes, JSON and request validation. FastAPI is an optional web framework; install dependencies into a virtual environment.

python -m pip install fastapi uvicorn
# app.py
from fastapi import FastAPI
app = FastAPI()
@app.get("/health")
def health():
    return {"status": "ok"}

# Start locally:
# python -m uvicorn app:app --reload

Development reload must not be used as a production process manager. API authentication and authorization belong server-side.

8. Testing and dependency control

Unit tests guard business logic; pinned/locked dependencies and scanning reduce supply-chain risk.

python -m pip install pytest
# test_shipping.py
def shipping_band(total):
    return "FREE" if total >= 100 else "PAID"

def test_shipping():
    assert shipping_band(120) == "FREE"

# run:
# python -m pytest

Document the supported Python version. Never put API keys or passwords directly into source control.

9. Enterprise capstone: CSV reconciliation

Write a command-line program that imports orders from CSV, validates types, groups amounts by customer, reports errors and emits JSON.

  • Isolate parsing, validation and aggregation in separate functions.
  • Use Decimal for currency and timezone-aware timestamps.
  • Use argparse for input/output paths, logging for diagnostics and pytest for unit tests.
  • Return a nonzero exit code when unrecoverable input errors occur.
  • Create README instructions and an example test dataset.
