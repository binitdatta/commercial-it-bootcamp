1. Understand the VS Code development environment

Visual Studio Code is a lightweight, extensible code editor. It is not the same product as the full Visual Studio IDE. Language servers, extensions, runtimes, SDKs, build tools and debuggers give it IDE-style capabilities.

ComponentPurpose
VS Code editorEditing, navigation, integrated terminal, debugging UI, extensions and source control UI.
OpenJDK 21Compiler and runtime for Java applications. Install the JDK separately; the editor is not the JDK.
Language extensionsAdd language-specific diagnostics, completion, tests, debugging and project support.
GitDistributed version-control software. Install Git separately and use VS Code as a client.
Workspace folderProject root containing source, configuration and possibly a .vscode/ directory.
Integrated terminalRuns your real local shell, such as zsh, PowerShell or bash.
Commercial engineering principle: An editor does not replace the compiler, build tool, database or Git executable. Know which program performs each responsibility and verify it independently.

2. Select the official VS Code distribution

Use the official Microsoft VS Code release from code.visualstudio.com/Download ↗. Choose the installer for your operating system and processor architecture. Check current system requirements before installation.

  • macOS: Universal download when offered, or a build suited to Apple Silicon (Arm64) or Intel (x64).
  • Windows: User Installer is often easiest without administrator privileges; System Installer is an option for managed machines.
  • Linux: Official .deb for Debian/Ubuntu, .rpm for Fedora/RHEL-family systems, or supported repository instructions.

Official installation guide ↗ · System requirements ↗

Security: Avoid third-party re-packaged installers. Follow employer endpoint-management policies on corporate laptops. Install only necessary extensions from trusted publishers.

3. Install VS Code on macOS

MacBook · Apple Silicon and Intel

1
Open the official download page; download the macOS build compatible with your system.
2
Open the downloaded ZIP, then drag Visual Studio Code.app into Applications. Launch it from Applications and complete any macOS confirmation prompts.
3
Press Cmd + Shift + P to open the Command Palette. Run Shell Command: Install 'code' command in PATH, then open a new Terminal window.
4
Verify the CLI and open a workspace:
code --version
mkdir -p ~/Development/internship-vscode
cd ~/Development/internship-vscode
code .

Optional: Homebrew Cask

If Homebrew is installed and the formula is available, use the cask. Do not install a second copy if you already have a managed/official application installation.

brew info --cask visual-studio-code
brew install --cask visual-studio-code
If code is not found: Re-run the Command Palette shell command, close and reopen Terminal, and retry code --version. On managed Macs, the command may need an alternate approved installation method.

4. Install VS Code on Windows

Windows 10 / Windows 11 · PowerShell

1
Download the User Installer for your CPU architecture from the official website. On a managed workstation, follow IT's deployment method.
2
Run the installer. Where offered, select Add to PATH and useful Explorer context-menu actions. Finish the installation and restart your shell.
3
Open PowerShell and verify:
code --version
New-Item -ItemType Directory -Force "$HOME\Development\internship-vscode"
Set-Location "$HOME\Development\internship-vscode"
code .

Alternative · Windows Package Manager

winget search --id Microsoft.VisualStudioCode
winget install --id Microsoft.VisualStudioCode --exact --source winget

When using winget, review the publisher/package shown by the search, confirm the installation result, and open a new terminal before checking code --version.

Do not confuse: VS Code with Microsoft Visual Studio, which has a different installer and product ID.

5. Install VS Code on Linux

Ubuntu / Debian / Fedora · Desktop Linux

Ubuntu / Debian: official DEB package

Download the appropriate .deb from the official VS Code download page, then from the directory containing that file:

sudo apt update
sudo apt install ./code_*.deb
code --version
code .

The glob should match only the downloaded official VS Code DEB. Alternatively, use the vendor's documented signed APT repository for ongoing updates.

Fedora / RHEL-family: official RPM package

Download the appropriate .rpm from Microsoft, then:

sudo dnf install ./code-*.rpm
code --version
code .

Verify architecture and launch

uname -m
command -v code
code --version
Important: VS Code is a GUI desktop application; a headless server typically uses Remote SSH from a local VS Code installation instead of running the full editor on the server. Package support and architectures vary by distribution.

6. Configure extensions and workspace settings

Open Extensions with Ctrl + Shift + X (Windows/Linux) or Cmd + Shift + X (Mac). Search for these extension IDs and verify the publisher before installing:

ExtensionPurpose / notes
vscjava.vscode-java-packExtension Pack for Java; Java language features, debugging, testing and project management.
vscjava.vscode-mavenMaven project support (included in typical Java pack configurations).
ms-python.pythonPython language support; interpreter selection and tooling integration.
ms-vscode-remote.remote-sshOptional remote development over SSH; use only approved hosts.
esbenp.prettier-vscodeOptional formatter for JavaScript, TypeScript, HTML, JSON and other supported files.

Installation via VS Code CLI (optional)

code --install-extension vscjava.vscode-java-pack
code --install-extension ms-python.python
code --list-extensions

Workspace settings example

Create a .vscode/settings.json file within a trusted project, as appropriate:

{
  "editor.formatOnSave": true,
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true,
  "editor.tabSize": 4
}
Workspace Trust: Open unfamiliar repositories in Restricted Mode until reviewed. Extension code, tasks, debug configurations and scripts may execute processes on your machine; only trust repositories and extensions after assessing them.

7. Connect VS Code to OpenJDK 21

Complete the OpenJDK 21 lesson first. VS Code must find a working JDK and the Java Extension Pack.

Validate Java before using the editor

java -version
javac -version
# macOS/Linux
printf '%s\n' "$JAVA_HOME"
# Windows PowerShell alternative:
# $env:JAVA_HOME

Tell the Java extension which JDK to use

  1. Open the Command Palette.
  2. Run Java: Configure Java Runtime.
  3. Inspect detected JDKs. Select or add the actual JDK 21 installation path for the project.
  4. Reopen the workspace if VS Code prompts you to refresh the Java language server.

For an explicit runtime mapping, VS Code Java settings support java.configuration.runtimes. Substitute the real local JDK home for the example path:

{
  "java.configuration.runtimes": [
    {
      "name": "JavaSE-21",
      "path": "/absolute/path/to/your/jdk-21",
      "default": true
    }
  ]
}
Important distinction: The Java language server may use a different JDK internally from the JDK used to build your project. Confirm your pom.xml/build.gradle language level and terminal java/javac versions align with the internship's Java 21 requirement.

8. Debugging, terminal and Git workflows

Integrated terminal

Use Terminal → New Terminal (or Ctrl + `) to build, test, run Git, inspect environmental variables and troubleshoot the program from the same project root.

Java debugging

  1. Open a Java source file in a trusted workspace with Java extensions enabled.
  2. Click in the left gutter to set a breakpoint.
  3. Select Run and Debug and start debugging (typically F5).
  4. Inspect Variables, Call Stack, Watch and step over / into methods.

Git and source control

git --version
git init
git status
git add HelloIntern.java
git commit -m "Add Java 21 VS Code internship lab"
git log --oneline -3

Use the Source Control sidebar to inspect file diffs and stage changes; the underlying repository remains a normal Git repository. Configure your own Git identity if a commit reports it is missing.

Good practice: Never commit passwords, API keys, OAuth client secrets, private keys or local .env files to Git. Review staged changes before committing.

9. Hands-on lab · Java 21 in VS Code

Lab objective: Demonstrate an end-to-end workflow: create a folder → open VS Code → write code → compile → debug → commit.

  1. Create a new folder internship-vscode and open it using code ..
  2. Make a file named HelloIntern.java containing the following code.
public class HelloIntern {
    public static void main(String[] args) {
        String student = "Intern";
        int completedLabs = 3;
        System.out.printf("Hello, %s! Completed labs: %d%n",
                student, completedLabs);
    }
}
  1. Open the integrated terminal and run:
javac HelloIntern.java
java HelloIntern

Expected output: Hello, Intern! Completed labs: 3

  1. Place a breakpoint on the System.out.printf statement, debug, and inspect the student and completedLabs variables.
  2. Change completedLabs to 4, save and rerun the program.
  3. Initialize a Git repository, inspect the diff and commit your completed exercise.

Optional advanced exercise · Maven project

Open an existing Java 21 Maven project and run mvn -version, then mvn test. Explain the distinction between VS Code, Maven and the JDK.

10. Troubleshooting common setup failures

SymptomLikely cause / corrective action
code: command not foundShell command not installed or terminal has stale PATH. Enable the CLI on macOS or use the installer PATH option on Windows; reopen terminal.
Java extension cannot find JDKCheck java -version, javac -version, JAVA_HOME and Java: Configure Java Runtime.
Code runs on wrong Java versionMultiple JDKs installed. Compare terminal paths, configured runtimes and build-tool compiler settings.
Java extension remains loadingWait for workspace indexing; inspect Java language-server logs, trust state and extension compatibility. Restart language server only if necessary.
VS Code cannot launch on LinuxVerify desktop session, supported architecture, complete package installation and required graphical libraries.
git is missingInstall Git SCM separately; reopen VS Code to refresh environment variables.
Run/debug not availableConfirm source folder is trusted, Java extensions are installed, the file is valid Java and a supported JDK is selected.
Extensions blockedCompany policy or restricted workspace. Do not bypass IT restrictions; seek approved extensions and distributions.
